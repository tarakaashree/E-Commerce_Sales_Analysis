# E-Commerce Sales Analysis

## Project Overview

This project focuses on analyzing an E-Commerce Sales dataset to uncover valuable business insights and support data-driven decision-making.

Using Python and popular data analysis libraries, I performed data cleaning, feature engineering, exploratory data analysis (EDA), business KPI evaluation, and data visualization to understand sales performance, customer behavior, profitability trends, and regional performance.

## Objectives

* Analyze sales and profit trends over time
* Identify top-performing product categories and sub-categories
* Evaluate the impact of discounts on profitability
* Discover high-performing countries and customer segments
* Generate actionable business insights and recommendations

## Tools & Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

1. Data Understanding
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Business KPI Analysis
5. Exploratory Data Analysis (EDA)
6. Data Visualization

## Key Insights

* Identified top-performing product categories and customer segments
* Analyzed sales growth patterns and seasonal trends
* Evaluated the relationship between discounts and profitability
* Compared regional and country-level sales performance
* Generated business recommendations based on data findings

## Conclusion

This project strengthened my practical understanding of data analysis, visualization, and business storytelling by applying Python skills to a real-world E-Commerce dataset.
